## 개요

### Problem — 두 사람이 각각 막혀 있었다

| | |
|---|---|
| **사용자 ①** | **크기 감각 부족** — 상세 페이지의 숫자만으로는 책상 위 실제 점유 공간을 예측하기 어렵다 |
| **사용자 ②** | **호환성 확인 부담** — 모니터 · 암 · 클램프 · 책상 두께 같은 조건을 사용자가 직접 비교해야 한다 |
| **사용자 ③** | **조합 확인 불가** — 제품 하나는 예뻐도 여럿이 함께 놓였을 때의 색감 · 비율은 알기 어렵다 |
| **사용자 ④** | **구매 연결 단절** — 커뮤니티 참고 이미지를 봐도 사용 제품과 내 공간 적용 여부가 바로 이어지지 않는다 |
| **브랜드** | 인테리어 플랫폼은 콘텐츠와 커머스가 강하지만, **책상 단위의 배치 · 호환성 검증은 공백**이다 |

| **콘텐츠** | 채널 · 홍보 전략 기획 · **숏폼 · 카드뉴스** 직접 기획 · 제작 |
| **리서치** | 데스크투어 **사용자 인터뷰 질문 설계** |

### 핵심 성과 · Key Achievements

- **수익화를 4단계로 쪼갰다** 처음부터 커머스를 하지 않습니다. **제휴 링크 → 브랜드 입점 → 추천 광고 → 내부 결제** 순으로, 앞 단계가 검증돼야 다음이 열리게 묶었습니다
- **규칙과 AI의 경계를 먼저 그었다** **물리적으로 가능한지는 규칙**, **취향에 맞는지는 AI**. AI가 “배치 가능 여부”를 판단하지 않게 선을 그어, 추천이 틀려도 서비스가 틀리지 않게 했습니다
- **검증 못 한 가정을 따로 적었다** 수수료율 · 3D 모델 제작 비용 · 초기 전환율 · 입점 패키지 가격. **추정치를 발표에서 과장하지 않는다**를 문서에 규칙으로 남겼습니다

## 의사결정

### BM 의사결정 — 왜 처음부터 커머스를 하지 않았나

수수료가 가장 큰 모델은 내부 결제입니다. 그런데 그건 **제품 데이터와 사용자가 이미 있을 때** 성립합니다. 없는 상태에서 결제부터 붙이면 팔 물건도 살 사람도 없습니다. 그래서 **앞 단계가 다음 단계의 조건**이 되도록 묶었습니다.

**구성도** — **4단계는 나열이 아니라 순서다** — 수수료가 가장 큰 건 4단계지만, 그건 앞의 셋이 끝나야 성립합니다.

> 수익화 4단계의 의존 관계. 외부 구매 링크에서 전환이 보이면 브랜드 입점이 열리고, 추천이 실제로 쓰이면 추천 광고가, 입점 브랜드가 쌓이면 커머스 확장이 열린다. 뒤로 갈수록 단계가 올라간다.

| 단계 | 무엇을 | 수익원 | 열리는 조건 |
|---|---|---|---|
| **1** 외부 구매 링크 | 제품 상세에서 판매처 연결 | 클릭 · 전환 기반 제휴 수수료 | 제품 데이터만 있으면 가능 |
| **2** 브랜드 입점 | 브랜드 제품 데이터 등록 | 3D 모델 노출 패키지 | 1단계에서 전환이 보여야 |
| **3** 추천 광고 | AI 추천 영역 스폰서 | 테마별 프로모션 | 추천이 실제로 쓰여야 |
| **4** 커머스 확장 | 내부 결제 · 판매 | 판매 수수료 · 브랜드 분석 리포트 | 입점 브랜드가 쌓여야 |

> **남의 사례에서 가져온 것** — 오늘의집은 콘텐츠·커뮤니티로 수요를 만들고 커머스·광고·입점으로 수익화했습니다. DERO가 가진 같은 자리의 자산은 **시뮬레이터에 쌓이는 배치 데이터**라고 보고, 그걸 수익화 접점으로 잡았습니다.

### 기획 의사결정 — 어디까지 AI에 맡길 것인가

추천을 전부 AI에 맡기면 **틀린 추천이 곧 틀린 서비스**가 됩니다. 책상에 안 들어가는 제품을 추천하는 순간 신뢰가 끝나기 때문입니다. 그래서 선을 먼저 그었습니다.

**구성도** — **병렬이 아니라 순서** — 규칙이 먼저 거르고, 남은 것 안에서만 AI가 고릅니다. 추천이 틀려도 서비스는 틀리지 않습니다.

> 추천 처리 순서. 책상 크기와 선호, 현재 배치를 입력받아 규칙 필터가 먼저 거르고, 규칙을 통과한 후보만 AI 랭킹으로 넘어가 추천과 근거를 낸다.

**규칙이 맡는 것 — 가능한가**

제품이 책상 크기 안에 들어가는가 · 클램프 설치가 가능한 두께인가 · 모니터와 암의 규격이 호환되는가 · 배치 가능 영역을 벗어나지 않는가

**AI가 맡는 것 — 어울리는가**

선호하는 스타일은 무엇인가 · 어떤 조합이 더 잘 어울리는가 · 현재 셋업에서 부족한 제품은 무엇인가 · 비슷한 분위기의 셋업은 무엇인가

> **원칙** — AI는 “배치 가능 여부”를 대신하지 않습니다. **규칙 기반 필터링을 통과한 뒤에만** 취향과 조합을 추천합니다.

## 회고

### 아직 검증하지 못한 것

| | |
|---|---|
| **수수료율** | 제휴 링크 수수료율과 **실제 적용 가능성** — 제휴처와 이야기해 본 적이 없습니다 |
| **제작 비용** | 데스크테리어 핵심 제품군의 **3D 모델 제작 비용** |
| **전환율** | 초기 사용자 **전환율 가정** — 근거가 되는 자사 데이터가 없습니다 |
| **가격 정책** | 브랜드 **입점 패키지 가격** |

> **이 문서는 사업 실적이 아니라 기획안입니다.** 실제 계약 · 매출 · 구매 전환이 확인되지 않았습니다. 발표자료에도 **“추정치는 과장하지 않는다”**를 규칙으로 적어두고, 검증이 필요한 항목을 부록에 따로 남겼습니다.

### 회고

| | |
|---|---|
| **배운 점** | 수익 모델을 그리는 일은 **숫자를 만드는 일이 아니라 순서를 정하는 일**이었습니다. 단계마다 “무엇이 있어야 이게 열리는가”를 적고 나서야 1단계가 왜 제휴 링크여야 하는지가 설명됐습니다. |
| **아쉬운 점** | 사용자 인터뷰 **질문은 설계했지만 실제로 돌리지 못했습니다.** 지금 가진 건 질문지이지 응답 데이터가 아닙니다. |
| **다음에는** | 가정을 적을 때 **그 가정을 깨뜨릴 수 있는 최소 실험**을 같은 줄에 적습니다. “전환율 가정”이 아니라 “링크 100개 붙여 2주 측정”처럼. |
